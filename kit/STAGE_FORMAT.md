# 스테이지 형식

팩 하나는 폴더 하나다.

```
packs/<교과>/<팩>/
  pack.json        팩 정보(이름, 단원, 만든 사람, 스테이지 목록)
  DESIGN.md        설계서
  stages/01.map.txt   글자 지도
  stages/01.json      글자의 뜻과 장치 값
  sprites/apple.txt   글자로 찍은 그림(있을 때만. 그리는 법은 kit/ART_GUIDE.md)
```

`<교과>` 와 `<팩>` 은 영문 소문자, 숫자, 줄표(-)만 쓰고 각각 40자까지다. sprites 의 그림 이름도 같다.

## pack.json

```json
{
  "id": "math/sample",
  "name": "팩 이름(40자까지)",
  "tagline": "한 줄 설명(30자까지)",
  "family": "수학",
  "schoolLevels": ["중학교"],
  "units": [{ "band": "ms2", "subject": "수학", "unit": "단원 이름" }],
  "educationalIntent": "이 게임으로 학생이 겪게 하려는 것",
  "description": "소개",
  "creator": { "nickname": "도름스 닉네임", "avatar": null },
  "players": { "min": 2, "max": 30 },
  "stages": [{ "file": "01", "name": "스테이지 이름", "difficulty": 1 }]
}
```

- `family` 는 도름스 오락실의 교과 묶음 이름과 같아야 한다: 국어, 영어, 수학, 사회, 역사, 도덕·윤리, 과학, 정보, 기술·가정, 음악, 미술, 연극, 체육, 한문·외국어, 교양, 통합교과, 창의적 체험활동, 기타.
- `difficulty` 는 1(쉬움)부터 5(어려움).
- `avatar` 는 `null` 로 둔다(만든 사람 그림은 기본 도름이로 보인다. 도름스로 보내는 길에서는 그림 파일을 받지 않는다).

## 글자 지도 (NN.map.txt)

한 글자가 한 칸(30px)이다. 줄 길이는 모두 같아야 한다. 가로 20~80칸, 세로 12~18칸.

| 글자 | 뜻 |
|---|---|
| `#` | 땅(막힌 칸) |
| `.` | 빈칸 |
| `@` | 시작 자리(한 곳. 도름이들이 이 둘레에 선다) |
| `K` | 열쇠 |
| `D` | 문(이 칸이 문의 왼쪽 아래. 문은 가로 2칸, 세로 3칸) |
| 영문 소문자, 숫자 | NN.json 의 `legend` 에서 뜻을 정한 장치 |

지도 바깥 왼쪽, 오른쪽, 위는 벽이다. 도름이가 아래로 떨어지면 시작 자리로 돌아오고, 상자가 아래로 빠지면 처음 놓인 자리로 돌아온다.

자리 약속(어기면 지도를 받지 않는다)
- `@` 바로 아래는 땅(`#`), 바로 위는 빈칸이어야 한다(도름이 키가 한 칸보다 크다).
- `D` 가 놓이는 가로 2칸, 세로 3칸은 빈칸이고 그 바로 아래 두 칸은 땅이어야 한다.
- 단추 바로 아래는 땅이어야 한다.

## 장치 (NN.json 의 legend)

```json
{
  "legend": {
    "a": { "type": "button", "need": 1, "opens": ["x"] },
    "x": { "type": "bridge" },
    "c": { "type": "crate", "need": "half" },
    "s": { "type": "sign", "texts": ["첫째 사람이 보는 글", "둘째 사람이 보는 글"] }
  },
  "hint": "처음에 화면 위에 잠깐 보이는 한 줄(60자까지, 없어도 됨)"
}
```

| type | 지도에 놓는 법 | 값 | 움직임 |
|---|---|---|---|
| `button` | 바닥 바로 위 칸에. 같은 글자를 옆으로 이어 놓으면 넓은 단추 하나 | `need`(안 적으면 1), `opens`(다리 글자 목록, 꼭 적는다) | `need` 명 이상이 밟고 있는 동안 `opens` 의 다리가 켜진다. 상자는 단추를 누르지 못한다 |
| `bridge` | 다리가 놓일 칸마다 | `mode`: `"appear"`(기본, 켜지면 생김) 또는 `"vanish"`(켜지면 사라짐) | 켜진 동안만 바뀐다. 어느 단추와도 이어지지 않으면 검사에서 떨어진다 |
| `crate` | 상자의 칸마다 같은 글자로 네모나게(예: 2×2). 붙여 놓은 같은 글자는 큰 상자 하나가 되니, 상자 둘은 다른 글자로 | `need`(안 적으면 2) | 한쪽에서 미는 사람이 맞은편보다 `need` 명 이상 많아야 움직인다(같은 수로 맞서면 멈춘다). 아래가 비면 떨어진다. 상자는 다른 상자를 밀지 못하고, 앞에 선 친구가 벽에 막히면 멈춘다 |
| `sign` | 표지를 세울 칸에 | `texts`(글 목록, 10개까지, 한 글은 40자까지) | 가까이 가면 글이 보인다. 사람마다 다른 글이 보인다(들어온 차례를 글 개수로 나눈 나머지) |
| `deco` | 꾸밈 그림을 세울 칸에(그림의 왼쪽 아래가 그 칸의 왼쪽 아래에 맞는다) | `sprite`(팩의 sprites 폴더에 있는 그림 이름) | 부딪히지 않고 도름이 뒤에 그려진다. 한 스테이지에 60개까지 |
| `pan` | 저울 접시. 같은 글자를 옆으로 6~8칸 이어 놓는다. 저울 하나에 왼쪽 접시 하나, 오른쪽 접시 하나 | `scale`(저울 이름), `side`: `"left"` 나 `"right"` | 아래 '저울' 참고 |
| `bin` | 통. 바닥 바로 위 칸에. 저울마다 하나 이상(양쪽에 하나씩 두면 좋다) | `scale` | 구슬을 버리거나 꺼내는 곳 |
| `lever` | 레버. 바닥 바로 위 칸에 | `scale`, `does`: `"addsub"`(더하기·빼기) 나 `"divide"`(나누기) | 확인 단추로 당긴다 |
| `wire` | 전선이 지나는 칸마다. 옆 · 위아래로 붙은 회로 칸끼리 이어진다 | 없음 | 부딪히지 않는다(도름이 뒤에 그려진다). 아래 '회로판' 참고 |
| `source` | 전지. 전선 사이 한 칸 | 없음 | 회로 하나에 꼭 하나 |
| `lamp` | 전구. 전선 사이 한 칸 | `opens`(다리 글자 목록), `when`: `"bright"`(밝게 켜지면 연다, 기본) 나 `"on"`(어둡게라도 켜지면 연다) | 회로가 이어지면 켜진다. 밝기는 실제 회로처럼 계산한다 |
| `contact` | 접점(끊긴 자리). 전선 사이 한 칸, 바로 아래는 땅 | 없음 | 도름이가 그 칸에 서 있는 동안 이어진다 |

적어 둔 것 말고 다른 칸 이름(오타 포함)을 쓰면 지도를 받지 않고 어느 칸인지 알려 준다.

### 저울 (NN.json 의 scales)

상자 하나가 x, 구슬 하나가 1, 풍선 하나가 -1이다. 두 접시의 무게가 같으면 수평이고, 한쪽만 손대면 기운다. x 가 얼마인지는 화면에 나오지 않는다.

```json
{
  "legend": {
    "l": { "type": "pan", "scale": "s", "side": "left" },
    "r": { "type": "pan", "scale": "s", "side": "right" },
    "u": { "type": "bin", "scale": "s" },
    "v": { "type": "lever", "scale": "s", "does": "addsub" },
    "w": { "type": "lever", "scale": "s", "does": "divide" },
    "x": { "type": "bridge" }
  },
  "scales": {
    "s": { "x": [2, 5], "left": { "boxes": 2, "marbles": [1, 4] }, "right": { "boxes": 0 }, "opens": ["x"], "spill": 0 }
  }
}
```

| 칸 | 뜻 |
|---|---|
| `x` | 상자 하나의 무게. 수 하나나 `[작은 수, 큰 수]`. 1~9 |
| `left.boxes`, `left.marbles` | 왼쪽 접시의 상자 수(1~6)와 구슬 수(-9~9). 구슬 수를 음수로 적으면 그만큼 풍선이 달린다(`"marbles": -3` 은 `x - 3`). 범위로 적으면 시작할 때마다 뽑는다. 안 적으면 상자 1개, 구슬 0개인데, 그러면 처음부터 x 만 남은 식이라 받지 않는다(상자를 2개 이상으로 하거나 구슬을 1개 이상으로 적는다) |
| `right.boxes` | 오른쪽 접시의 상자 수(0~5). 왼쪽보다 늘 적어야 한다. 오른쪽 구슬 수는 저울이 수평이 되게 판이 계산한다(30개를 넘으면 받지 않는다) |
| `opens` | x 만 남았을 때 켜지는 다리 글자 목록. 한 번 켜지면 꺼지지 않는다 |
| `skin` | `{ "marble": "apple", "box": "basket" }` 처럼 구슬과 상자 대신 그릴 팩의 그림(구슬 9×9점, 상자 18×18점까지). 안 적으면 기본 그림 |
| `spill` | 기운 채로 이 시간(초, 2~60)이 지나면 쏟아져 처음 식으로 돌아간다. 0 이나 안 적으면 쏟아지지 않는다. 혼자서는 못 풀게 하려면 통을 접시에서 여섯 칸쯤 떼고 3초로 둔다(한 사람이 한쪽을 바꾸고 통을 거쳐 맞은편까지 걸어가는 시간보다 짧아야 한다. 검사가 이 거리를 잰다) |

위 예는 `2x + 3 = 11` 같은 식이 된다. 수는 할 때마다 바뀌고 답은 늘 자연수다.

움직임
- **들고 놓기**: 접시 밑에 서서 확인을 누르면 하나를 든다(접시의 왼쪽 칸 밑에서는 상자, 오른쪽 칸 밑에서는 구슬. 그 칸이 비어 있으면 다른 것을 든다). 든 채로 접시 밑에서 확인을 누르면 올려놓는다. 한 사람이 한 번에 하나만 든다. 접시 하나에는 상자 6개, 구슬 30개까지 올라간다. 다른 저울에서 가져온 것은 올려놓지도, 그 저울의 통에 버리지도 못한다.
- **풍선**: 풍선은 뗄 수 없다. 풍선이 달린 접시에 구슬을 올리면 풍선 하나와 구슬 하나가 함께 사라진다. 그래서 `x - 3 = 5` 는 통에서 구슬을 꺼내 양쪽에 3개씩 올려야 풀린다(양변에 3을 더한다).
- **통**: 더하기·빼기 레버가 '빼기'일 때 든 것을 버릴 수 있고, '더하기'일 때 빈손으로 구슬을 꺼낼 수 있다. 처음에는 '더하기'다. 그 레버가 없는 저울의 통은 둘 다 된다.
- **나누기 레버**: 저울이 수평이고 접시 위 모든 묶음이 똑같이 나뉠 때만 된다. 나눌 수 있는 가장 큰 수로 나눠 한 묶음만 남긴다(`2x = 8` 이면 `x = 4`). `2x + 3 = 11` 처럼 못 나누면 덜컹거리고 걸린다.
- **풀이 판**: 저울이 수평으로 돌아와 반 초쯤 이어지면 그때의 식이 한 줄 적히고, 줄 사이에 "양변에서 3을 뺀다" 같은 말이 붙는다. 구슬을 더하고 빼는 일을 이어서 하면 앞 줄에서 본 결과 한 줄로 모인다(1씩 세 번 빼면 "3을 뺀다", 둘을 뺐다가 하나를 도로 올리면 "1을 뺀다"). 앞 줄의 식으로 되돌아가면 줄이 지워진다. 판에는 마지막 네 줄이 보인다.
- **풀림**: 한쪽에 상자 하나만, 맞은편에 구슬만 남은 채 1.5초 가만히 수평이면 풀린다(`x = 4`). 풀린 저울은 더 손댈 수 없다.
- 양쪽 상자 수가 같아지면 x 를 알 수 없으므로 바로 앞 줄로 되돌아간다.
- 든 채로 떨어지거나 문에 들어가거나 방에서 나가면 든 것은 꺼낸 접시로 돌아간다(통에서 꺼낸 구슬은 사라진다). 저울이 쏟아지거나 되돌아가거나 풀리면 그 저울의 것을 든 손은 빈다.

자리 약속
- 접시 아래 세 칸은 비우고 그 아래(네 칸 아래)는 땅이어야 한다. 접시 위 세 칸도 비운다. 접시는 위에서 여덟째 줄이나 그 아래에 놓는다(위에 풀이 판이 걸린다).
- 접시 아래 세 칸에는 다른 장치도 두지 않는다. 통과 레버는 접시 밑과 바로 옆 칸을 피해 한 칸 넘게 띄워 놓는다(붙여 놓으면 확인을 누를 때 들고 놓기 대신 통이나 레버가 움직인다).
- 두 접시는 같은 높이에, 왼쪽 접시가 왼쪽에, 사이를 두 칸 이상 띄운다(가운데에 기둥이 선다).
- 상자가 둘 이상 남을 수 있는 식이면 나누기 레버를 꼭 놓는다.
- 시작 자리(@)는 접시에서 열 칸쯤 떨어뜨린다. 사람이 많으면 시작 줄이 세 층으로 쌓여 접시를 가린다.
- 저울은 한 스테이지에 6대까지. 사람이 많으면 여러 대를 놓고 모두 풀려야 길이 열리게 한다.

### 회로판 (wire, source, lamp, contact)

배경에 회로도를 그린다. 전지 · 전구 · 접점은 양쪽에 전선이 한 칸씩(옆으로든 위아래로든) 꼭 두 곳만 붙어야 하고, 부품끼리 바로 붙으면 안 된다(사이에 전선 한 칸). 붙어 있는 회로 칸 덩어리 하나가 회로 하나이고, 회로마다 전지가 꼭 하나 있다.

```
wwwwlwwww     l 전구 (opens: ["x"])
w.......w     b 전지
b.......w     c 접점: 도름이가 서면 이어진다(바로 아래는 땅)
w.......w
wwwwcwwww
#########
```

계산은 실제 회로와 같다(전지 전압 1, 전구 저항 1, 전선과 닫힌 접점은 저항이 거의 0).

| 이어진 모양 | 전구 하나의 밝기 | when "bright" | when "on" |
|---|---|---|---|
| 전구 하나 | 1 | 연다 | 연다 |
| 한 줄로 전구 둘 | 1/4 (어둡게) | 안 연다 | 연다 |
| 한 줄로 전구 셋 | 1/9 | 안 연다 | 연다 |
| 갈래로 전구 둘 | 하나마다 1 | 연다 | 연다 |
| 전지 양 끝이 전구 없이 이어짐(합선) | 그 회로 전구 모두 0, 전지에 불꽃 | 안 연다 | 안 연다 |

- 흐르는 전선은 노랗게 빛난다. 끊긴 갈래나 막다른 전선은 갈림길에 붙어 있어도 빛나지 않는다(전류가 흐르는 곳만 보인다). 흐르는 방향은 그리지 않는다.
- 접점 바닥에는 '여기 서요' 발판이 그려진다. 몸이 칸에 닿기만 하면 이어진다(지나가며 스쳐도 그동안은 이어진다).
- 전구가 연 다리는 그 전구가 켜져 있는 동안만 있다.
- 회로 칸은 한 스테이지에 600칸, 회로 하나의 전선은 300칸, 회로(전지)는 6개, 전구는 12개, 접점은 16개까지.
- 접점을 여러 층에 두려면 선반을 두 칸씩 높게 쌓고 옆으로 붙여 놓는다. 세 칸 높이로 떠 있는 선반은 밑으로 파고들어 머리를 찧기 쉽다.
- 봇은 아직 회로판을 다루지 못한다. 회로판 스테이지는 봇 검사에서 '확인 못 함'이 나오니 사람이 직접 끝까지 깨 본다.

### 필요 인원(need)

| 값 | 뜻 |
|---|---|
| 숫자 | 그 수만큼(방 인원보다 크면 방 인원으로 낮춘다) |
| `"half"` | 방 인원의 절반(올림) |
| `"third"` | 방 인원의 3분의 1(올림) |
| `"all"` | 모두 |

2명에서도 30명에서도 풀리게 하려면 숫자보다 `"half"`, `"all"` 을 쓴다.

## 끝나는 조건

열쇠를 든 도름이가 문에 닿으면 문이 열린다. 열린 문 앞에서 확인 단추를 누르면 들어가고, **모든 도름이가 들어가면** 스테이지가 끝난다. 문 안에서 확인을 다시 누르면 나온다(먼저 들어간 친구가 남은 친구를 도우러 나올 수 있다).

## 끝까지 깰 수 있는지 확인

`npm run play:bots -- <교과>/<팩>` 을 돌리면 봇이 가장 적은 인원, 8명, 30명으로 스테이지마다 끝까지 깨 보고 한 줄씩 알려 줘요(`--players 8`, `--stage 01` 로 좁힐 수 있어요). 팩 검사(`npm run check:packs`)도 같은 봇을 돌려 못 깨는 스테이지를 걸러요. 봇은 단추 지키기, 상자 밀기, 저울 풀기, 친구 한 명 머리 딛기만 해요. 친구 둘 이상을 쌓아야 하는 길처럼 봇이 못 하는 길만 남으면 '확인 못 함'으로 알려 주니, 그 인원은 화면에서 직접 깨 보세요.

## 조작과 몸

- 움직이기(좌우), 뛰기, 확인 세 가지다. 확인은 열린 문에 들어갈 때, 저울의 구슬과 상자를 들고 놓을 때, 레버를 당길 때 쓴다.
- 도름이끼리는 서로 막힌다. 옆으로 지나가지 못하고, 머리 위에는 올라설 수 있다. 좁은 길에 여럿을 지나가게 하려면 뛰어넘을 높이를 남긴다.
- 상자는 줄지어 밀어도 된다(앞사람이 밀고 있으면 뒤에 붙어 미는 사람도 센다). 줄 가운데 한 명이 안 밀면 그 뒤는 세지 않는다.
- 머리 위에 친구가 서 있으면 뛰어오르지 못한다.
- 혼자 남으면 못 푸는 자리를 만들지 않는다. 예: 다리를 붙잡는 단추는 건너편에도 하나 둔다.

## 하지 않는 것

- 문제 창, "정답"과 "오답" 문구.
- 팩 폴더 안에 코드 파일이나 다른 파일을 두는 것. pack.json, DESIGN.md, stages 폴더(NN.json, NN.map.txt), sprites 폴더(글자 그림 .txt)만 둘 수 있다.
- 바깥에서 가져온 그림 파일을 스테이지에 쓰는 것. 스테이지의 그림은 글자 그림으로만 그린다(화풍을 하나로 지키려는 약속).
- 바깥 주소, 학생 개인정보.

## 설계할 때 알아 둘 수치

판(`platform/sim.ts`, `render.ts`)이 정한 값이다. 지도를 그리기 전에 본다. 한 칸은 30px 이다.

| 알고 싶은 것 | 값 |
|---|---|
| 얼마나 높이 뛰나 | 세 칸 턱은 뛰어오르고 네 칸은 못 오른다. 친구 머리나 상자 하나를 딛으면 네 칸도 오른다 |
| 얼마나 멀리 뛰나 | 세 칸 구덩이는 혼자 뛰어 건넌다. 혼자 못 건너게 하려면 다섯 칸 이상으로 판다 |
| 도름이 크기 | 한 칸보다 좁고(22px) 한 칸보다 크다(38px). 한 칸 틈으로 떨어지고, 한 칸 높이 굴은 못 지나간다 |
| 넓은 단추에 몇 명 서나 | 땅에 선 사람만 센다(친구 머리 위에 선 사람은 안 센다). 30명의 3분의 1(10명)이 서려면 여덟 칸으로 넓힌다 |
| 상자가 빠지는 구멍 | 상자는 자기 너비만 한 구멍에만 빠진다. 두 칸 상자는 한 칸 틈 위를 지나간다. 넓은 상자로 구멍을 건너게 하려면 구멍은 한 칸까지만(더 넓으면 미는 사람이 먼저 빠져 상자가 멈춘다) |
| 상자가 다리 두 칸에 걸치면 | 한 칸이라도 받치고 있으면 안 떨어진다. 받침 두 칸을 서로 다른 단추에 이으면 둘을 같이 밟아야 떨어진다 |
| 사라지는 다리 위의 상자 | 다리가 사라질 때 떨어진다 |
| 상자를 벽에 붙이면 | 상자는 당길 수 없다. 벽이나 다른 상자에 붙여 버리면 다시 못 뗀다. 상자 둘을 나란히 붙여 놓지 않는다 |
| 꾸밈 그림이 가리는 것 | 꾸밈은 땅과 다리 위, 단추와 상자와 도름이 뒤에 그려진다 |
| 한 화면에 보이는 넓이 | 가로 32칸, 세로 18칸. 내 도름이를 따라 움직인다 |
| 30명이 처음 서는 자리 | `@` 오른쪽으로 여덟 칸, 위로 네 칸을 비워 둔다(열 명씩 세 층으로 선다) |
| 2명일 때의 필요 인원 | `"third"`, `"half"` 는 2명이면 1명이 된다. 2명에서도 둘이 꼭 필요하게 하려면 서로 떨어진 단추 둘을 같이 밟게 한다 |
| 표지의 글 | 가까이 가야 보인다. 늘 보여야 하는 이름표로는 쓸 수 없다 |
| 학년(band)과 단원 이름 | 도름스 오락실의 것과 글자까지 같아야 한다. `npm run units` 로 본다 |
