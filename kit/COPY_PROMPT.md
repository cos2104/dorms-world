# 선생님이 자기 AI 에게 붙여 넣는 안내문

아래를 그대로 복사해 AI(Claude Code, Codex 등 내 컴퓨터에서 도는 코딩 AI)에 붙여 넣으세요. `dorms.school/world` 의 '게임 만들기'에서도 복사할 수 있어요.

```
도름스 월드에 올릴 협력 게임을 나와 같이 만들자.

1. https://github.com/shinnanchanguk/dorms-world 를 이 컴퓨터에 내려받아 줘(git clone). 이미 있으면 최신으로 맞춰 줘(git pull).
2. 그 폴더에서 kit/skills/coop-game/SKILL.md 를 읽고, 거기 적힌 순서대로 나를 이끌어 줘.
3. 먼저 게임을 내 컴퓨터에 띄워서 화면을 보여 주고, 내 수업 자료를 달라고 하거나 어떤 내용을 게임으로 만들고 싶은지 물어봐 줘.
4. 아이디어는 너도 내고 나도 낼게. 만들기 전에 설계를 같이 정하자.
5. 다 만들면 내가 직접 해 본 뒤에 요청 올리는 것까지 도와줘.
```

알아 두실 것
- 필요한 것: 내 컴퓨터에서 도는 코딩 AI, Node.js, Git, 그리고 요청을 올릴 때 쓸 GitHub 계정. 없는 것은 AI 가 설치를 도와줘요.
- 수업 자료는 선생님 컴퓨터에서 선생님의 AI 가 읽어요. 도름스로 올라가지 않아요. 다만 선생님이 쓰는 AI 서비스에는 내용이 전달되니 학생 이름, 성적, 연락처가 든 파일은 빼고 주세요.
- 순서: 준비(게임 띄우기) → 자료 읽기 → 아이디어 같이 내기 → 몇 가지 여쭙기 → 브로콜리 점검 → 설계서 확인 → 만들기 → 직접 해 보기 → 검사 → 요청 올리기.
- 요청을 올리면 운영자에게 도름스 쪽지가 가요. 운영자가 직접 해 보고 승인하면 `dorms.school/world` 에 실려요.
- 올라가는 것은 팩 폴더(설계서, 지도, 그림)와 도름스 닉네임이에요. 누구나 볼 수 있는 곳에 올라가니 학생 이름과 사진은 넣지 마세요.
