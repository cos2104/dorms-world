# 그림 넣기 (글자로 찍는 점 그림)

수업 내용에 맞는 그림(위, 소장, 음식, 악기, 화산 …)이 필요하면 팩 안에 직접 그려 넣는다. 그림 파일을 따로 만들지 않고 **글자로 찍는다**: 한 글자가 한 점이다. 쓸 수 있는 물감이 정해져 있어서 누가 그려도 도름스 월드의 화풍에서 벗어나지 않는다.

## 어디에 두나

```
packs/<교과>/<팩>/sprites/stomach.txt     이름은 영문 소문자, 숫자, 줄표
```

팩 하나에 40개까지. 한 그림은 가로세로 3~48점.

## 화풍 약속 (검사가 본다)

- **가장자리는 윤곽으로 두른다.** 빈 점이나 그림 끝과 맞닿은 점은 남색(`n`)이나 파랑(`b`)이어야 한다(가장자리의 90% 이상).
- 모든 줄의 길이가 같다.
- 한 그림에 색은 서너 가지면 충분하다. 면은 한 색으로 평평하게 칠하고, 밝은 점(`w`) 하나둘로 반짝임을 준다. 번지는 그늘(색을 여러 단계로 섞기)은 쓰지 않는다.
- 글자나 숫자를 그림 안에 그려 넣지 않는다(작아서 읽히지 않는다. 글은 표지 `sign` 에 쓴다).
- 실제 상표, 사람 얼굴, 남의 캐릭터를 그리지 않는다.

본보기(사과, 9×9):

```
....n....
...nn....
.nnnnnnn.
nrrrrrrrn
nrwrrrrrn
nrrrrrrrn
nrrrrrrrn
.nrrrrrn.
..nnnnn..
```

더 큰 본보기는 `packs/etc/tutorial/sprites/tree.txt`.

## 스테이지에서 쓰기

꾸밈으로 세우기(부딪히지 않고 도름이 뒤에 그려진다. 한 점이 2px 이라 15점이 한 칸):

```json
"legend": { "e": { "type": "deco", "sprite": "tree" } }
```

지도에 `e` 를 놓은 칸의 **왼쪽 아래**에 그림의 왼쪽 아래가 맞는다. 땅 위에 세우려면 땅 바로 윗줄에 놓는다. 한 스테이지에 60개까지.

저울의 구슬과 상자를 다른 그림으로(한 점이 1px. 구슬은 9×9점, 상자는 18×18점까지):

```json
"scales": { "s": { "skin": { "marble": "apple", "box": "basket" }, "x": [2, 4], "left": { "boxes": 2, "marbles": [1, 3] } } }
```

## 그린 뒤에

1. `npm run check:packs` 로 약속에 맞는지 본다. 어긋나면 어느 그림의 어디가 왜 안 맞는지 알려 준다.
2. 개발 서버 화면에서 **직접 본다**. 글자로는 그럴듯해도 화면에서는 뭉개져 보일 수 있다. 무엇인지 한눈에 알아볼 수 없으면 더 크게, 더 단순하게 다시 그린다.
3. 선생님께 화면을 보여 드리고 "이게 무엇으로 보이세요?"라고 여쭌다.
