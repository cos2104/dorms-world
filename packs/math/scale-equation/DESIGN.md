# 설계서: 저울로 푸는 일차방정식

## 한눈에
- 교과와 단원: 수학, 문자와 식(일차방정식)
- 학년: 중학교 1학년
- 수업에서 쓰는 자리와 시간: 아직 여쭙지 못함(선생님이 바로 만들자고 하셔서 4단계 질문을 다 하지 못했다)
- 인원과 방식(각자 기기 / 함께 보기): 2~30명. 방식은 아직 여쭙지 못함
- 만든 사람(도름스 닉네임): 홍창욱

## 꼭 남길 한 가지
선생님 답: "둘 다지". 아래 두 문장을 드리고 받은 답이다.
1. 등식의 양변에 같은 일을 하면 등식은 그대로다.
2. x만 남기려고 양변에 같은 일을 차례로 한다(먼저 빼고, 그다음 나눈다).

## 학생이 자주 헷갈리는 것
아직 여쭙지 못함. 선생님이 알려 주시면 그것이 화면에서 드러나는 스테이지를 더한다.

## 개념과 장치

| 수업의 개념 | 게임에서 하는 일 | 쓰는 장치 | 틀리면 화면에서 보이는 것 |
|---|---|---|---|
| 방정식(등식) | 저울이 수평이다. 상자 하나가 x, 구슬 하나가 1 | 저울 | 수평이 아니면 식이 아니다. 저울이 기운다 |
| 양변에서 같은 수를 뺀다 | 좌변 쪽과 우변 쪽이 구슬을 같은 수만큼 같이 들어다 통에 버린다 | 접시, 통, 더하기·빼기 레버 | 한쪽만 덜면 기울고, 3초(마지막 스테이지는 2초) 안에 맞추지 못하면 쏟아져 처음 식으로 돌아간다 |
| 양변에서 x를 뺀다 | 양쪽 접시에서 상자를 같이 들어낸다 | 접시, 통 | 상자 무게를 몰라서, 한쪽 상자만 덜면 구슬로는 맞추기 어렵다 |
| 양변에 같은 수를 더한다 | 풍선(-1)이 달린 접시와 맞은편에 구슬을 같이 올린다. 풍선과 구슬이 만나 사라진다 | 풍선, 통, 더하기·빼기 레버 | 풍선은 뗄 수 없다. 한쪽에만 올리면 기운다 |
| 양변을 같은 수로 나눈다 | 나누기 레버를 당기면 양쪽이 똑같은 묶음으로 갈라지고 한 묶음만 남는다 | 나누기 레버 | 2x + 3 = 11 처럼 똑같이 못 나누면 레버가 덜컹거리며 걸린다(먼저 빼야 한다) |
| 풀이를 한 줄씩 쓴다 | 저울이 수평으로 돌아올 때마다 그때의 식과 양변에 한 일이 풀이 판에 적힌다 | 풀이 판 | 기운 채로는 줄이 늘지 않는다 |
| 해 | 한쪽에 상자 하나, 맞은편에 구슬만 남는다(x = 4) | 저울, 다리 | 상자가 양쪽에 같은 수로 남으면 x를 알 수 없어 앞 줄로 돌아간다 |

## 왜 혼자서는 안 되는가
- 한 사람은 한 번에 하나만 든다. 한쪽을 덜고 통에 버린 뒤 맞은편까지 가면 3초가 넘어 저울이 쏟아진다. 손이 닿는 가장 가까운 자리끼리 이어도 걷는 거리가 모자라지 않게 통을 접시에서 여섯 칸 떼었고, 검사가 스테이지마다 이 거리를 잰다.
- 그래서 좌변 쪽 사람과 우변 쪽 사람이 "하나, 둘, 셋" 하고 같이 움직여야 한다. 무엇을 몇 개 뺄지, 지금 빼기인지 더하기인지, 언제 나눌지를 말로 맞추게 된다.
- 레버는 가운데에 있어서 넷 이상이면 레버를 맡는 사람이 따로 생긴다(더하기·빼기 레버 한 명, 나누기 레버 한 명, 좌변 쪽, 우변 쪽).
- 마지막 스테이지는 저울이 둘이라 사람이 많으면 두 모둠으로 나뉘어 한꺼번에 푼다.

## 스테이지

식의 수는 범위만 정해 두고 할 때마다 뽑는다. 답은 늘 자연수다.

| 번호 | 이름 | 난이도(1~5) | 새로 나오는 것 | 깨는 길 한 줄 |
|---|---|---|---|---|
| 01 | 같이 덜어 내기 | 1 | 저울, 들고 놓기, 통 (x + b = c) | 양쪽에서 구슬을 b개씩 같이 덜어 상자만 남긴다 |
| 02 | 덜고 나서 나누기 | 2 | 더하기·빼기 레버, 나누기 레버 (ax + b = c) | 레버를 빼기로, b개씩 같이 덜고, 나눈다. 구슬이 상자 수로 안 나뉘는 식은 먼저 나누려 하면 걸린다(2x + 4 = 8 처럼 다 나뉘는 식은 먼저 나눠도 된다) |
| 03 | 양쪽에 상자 | 3 | 상자도 덜기 (ax + b = cx + d) | 상자를 양쪽에서 같이 덜고, 구슬을 덜고, 나눈다 |
| 04 | 풍선 터뜨리기 | 3 | 풍선 (ax - b = c) | 통에서 구슬을 꺼내 양쪽에 b개씩 같이 올리고, 나눈다 |
| 05 | 저울 둘 | 5 | 저울 두 대, 더하기와 빼기를 오가기 (ax - b = c, ax - b = x + d) | 두 저울을 다 풀어야 구덩이 둘이 이어진다 |

### 01 스케치
```
                  [   x + 3 = 7   ]            풀이 판
              ==========저울대==========
        [ X . ooo ]            [ . ooooooo ]   접시(X 상자, o 구슬)
 @     U                                  U         K    D
#############################################.....########
```
U 는 통이다. 02~04 는 같은 자리에 가운데 레버 둘(v 더하기·빼기, w 나누기)이 더해진다.

### 05 스케치
```
        저울 a (2x - 3 = 5)            저울 b (3x - 2 = x + 6)
     [ XX 풍선 ]   [ ooooo ]        [ XXX 풍선 ]   [ X oooooo ]
 @  U        v w          U  U          q t            U     K D
#############################################################xxxxx#yyyyy###
```
a 가 풀리면 x 구덩이가, b 가 풀리면 y 구덩이가 이어진다.

## 브로콜리 점검 결과

| 질문 | 답 | 고친 것 |
|---|---|---|
| 개념을 몰라도 깨지나 | 마구 누르는 봇은 한 판 시간 안에 한 번도 못 풀었다. 다만 5분을 주면 가장 쉬운 식은 30번에 4번 풀렸다 | 쏟아지면 '앞 줄'이 아니라 '처음 식'으로 돌아가게 하고, x만 남은 채 1.5초 가만히 수평이어야 풀리게 했다 |
| 혼자서도 깨지나 | 안 된다(쏟아지는 시간 3초, 마지막 스테이지 2초) | 처음 5초와 4초에서는 접시와 통의 가장자리에 서서 오가는 길로 혼자 풀 수 있었다. 3초로 줄이고, 검사를 '손이 닿는 가장 가까운 자리끼리 잰 거리'로 바꿨다 |
| 서로 말을 해야 풀리나 | 무엇을 몇 개, 언제 같이 할지 맞춰야 한다 | |
| 문제 창이나 정답과 오답 문구가 있나 | 없다. 저울이 기울고, 레버가 걸리고, 쏟아진다 | |
| 아무렇게나 눌러도 깨지나 | 위 첫 줄과 같다. 오른쪽으로 달리며 뛰기만 해서는 구덩이를 못 건넌다 | 구덩이를 세 칸에서 다섯 칸으로(세 칸은 혼자 뛰어 건넜다) |
| 게임 조작과 개념이 같은 일인가 | 같다. 양쪽에 같은 일을 해야 수평이 유지되는 것이 곧 등식의 성질이다 | |
| 꼭 남길 한 가지와 이어지나 | 풀이 판에 "양변에서 3을 뺀다", "양변을 2로 나눈다"가 학생이 한 일 그대로 남는다 | |

남은 걱정
- 저울을 '무게 재는 도구'로 써서 시행착오로 맞추는 길이 완전히 막히지는 않았다(한쪽 상자를 덜고 맞은편 구슬을 3초 안에 어림해 덜기). 느리고 틀리면 처음으로 돌아가지만, 선생님이 직접 해 보시고 판단해 주셔야 한다.
- 01·02 는 레버나 통이 한 번 쓰이고 마는 역할이라 레버 담당이 심심할 수 있다.

## 아이디어 기록
- 선생님: 식을 저울로 나타내기(x 는 상자, 계수는 상자 개수, 상수는 구슬), 숫자를 입력하지 않고 구슬을 나르기, 더하기·빼기 레버와 곱하기·나누기 레버를 한 명씩 맡기, 좌변 쪽 사람과 우변 쪽 사람, 한쪽만 하면 저울이 왔다 갔다 하기, 목표는 x = □ 꼴, 식의 수가 할 때마다 바뀌기.
- AI: 수평으로 돌아올 때마다 풀이 한 줄이 적히기, 나누기는 레버가 하고 못 나누면 걸리기, 사람이 많으면 저울 여러 대, 음수는 풍선으로(구슬과 만나면 함께 사라짐), 쏟아지는 저울로 혼자서는 못 하게 하기.
- 경사하강법 세 안(AI)은 선생님이 접어 두셨다.

## 의견
- 처음 받은 아이디어가 판에 없던 장치(저울, 드는 구슬, 통, 레버, 풍선)를 요구했다. 판에 새로 넣었다.
- 곱하기(양변에 같은 수를 곱한다)는 아직 없다. 반쪽 상자 같은 장치가 필요하다.
- 계수가 음수인 식, 괄호가 있는 식, 해가 음수이거나 분수인 식은 이 저울로 나타내지 못한다.
- 좌변 쪽과 우변 쪽을 벽으로 갈라 서로 건너가지 못하게 하면 역할이 더 또렷해질 것 같다(지금은 쏟아지는 시간으로만 막는다).
- 휴대폰 가로 화면에서는 터치 단추가 화면 아래 구석의 통을 가린다.
- 쏟아지는 시간 3초가 처음 하는 학생에게 너무 빠듯한지는 교실에서 봐야 안다.
