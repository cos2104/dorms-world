# 피코파크와 조작 · 규칙 대조 (2026-11-19)

형 지시: "피코파크랑 완전히 게임 조작법이나 그런게 100% 일치하는지 제대로 검증해."
캐릭터 · 레벨 · 그림 · 이름은 우리 것이고, 맞추는 것은 조작과 규칙이다.
